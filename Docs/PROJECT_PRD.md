# 亡者呼喚 Spirits Calling — 專案需求規格書 (PRD)

## 1. 專案目標
- 打造具國際競爭力的跨平台策略召喚遊戲
- 提供文化教育與健康促進的數位娛樂體驗

## 2. 目標用戶
- RTS 玩家、VR 體驗者、文化愛好者

## 3. 功能需求
- 登入/註冊/雲端同步
- 靈魂附身／文明切換／戰場控制
- VR 動作法陣、冥想互動
- 健康 APP 整合
- 多人競技、公會、排行榜

## 4. 非功能需求
- 高效能、多語言、跨平台
- 資料安全、隱私保護
- 良好可擴展性

## 5. 里程碑
- Alpha、Beta、正式版、跨平台整合
