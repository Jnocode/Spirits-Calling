# 亡者呼喚 Spirits Calling — 完整遊戲設計總結

## 1. 遊戲核心理念
- 四大文明召喚體系，結合靈魂附身戰術
- 支援 PC 與 VR 跨平台
- 強調文化教育與健康促進

- 靈魂附身機制：第一人稱附身召喚生物，戰場戰術自由切換

- VR 互動：動作法陣、冥想恢復、空間探索

## 3. 藝術與音效設計

## 4. 多人模式

- 雲端同步跨平台進度

## 5. 商業模式
- 單次購買、季票、文化包 DLC、教育授權

## 6. 健康與教育
