# Spirits Calling — Early Access Release Scope

This document is the store-scope declaration for the Early Access release. It describes shipped claims only; approval and store evidence remain release-owner gates.

## Included in shipped scope

- PC single-player
- LAN/friend connection
- PCVR

## Explicitly not shipped in this release

- public matchmaking is not shipped.
- dedicated servers are not shipped.
- Nakama authentication is not shipped.
- anti-cheat is not shipped.

The multiplayer claim is limited to Windows listen-server LAN and direct friend connection. No statement above is evidence that a hardware, Steamworks, legal, or store-material gate has passed.
